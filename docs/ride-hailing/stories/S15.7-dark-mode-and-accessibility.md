## User story
**As a** user,
**I want** dark mode, large text and screen-reader support,
**so that** the app works for everyone in any light.

## Acceptance criteria
- [ ] All ride screens support system dark mode via theme tokens.
- [ ] Every touchable has an accessibility label; layouts work at 200% font scale.
- [ ] Contrast ratio ≥ 4.5:1 for text.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
