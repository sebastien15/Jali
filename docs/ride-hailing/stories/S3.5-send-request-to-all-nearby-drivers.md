## User story
**As a** rider in a hurry,
**I want** to send my request to all nearby drivers under a maximum price,
**so that** I get the fastest pickup without browsing.

## Acceptance criteria
- [ ] `mode=broadcast` with optional `max_fare` dispatches to up to N nearest drivers whose quote ≤ max fare.
- [ ] The first driver to accept wins; the others see *Ride taken* and the card disappears.
- [ ] The rider sees the winning driver's quote (always ≤ max fare).
- [ ] Dispatches are recorded in `ride_dispatches`.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
