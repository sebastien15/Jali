## User story
**As a** rider,
**I want** the app to suggest the nearest good pickup point (gate, main road, landmark),
**so that** the driver finds me fast even without a street address.

## Acceptance criteria
- [ ] When I set a pin, up to 3 nearby suggested points appear (admin-curated + learned from past successful pickups).
- [ ] Admin can create named pickup points for malls, hotels, hospitals, airport, stadium.
- [ ] Venue zones force the venue's official pickup point.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
