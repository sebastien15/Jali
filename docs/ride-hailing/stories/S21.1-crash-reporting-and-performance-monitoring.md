## User story
**As a** developer,
**I want** crashes and slow screens reported automatically with context,
**so that** we fix problems before users complain.

## Acceptance criteria

- [ ] Alerts for new crash types and crash-free rate < 99.5%.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
