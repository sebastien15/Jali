## User story
**As a** admin,
**I want** to see online drivers and active rides in real time,
**so that** I can spot problems and supply gaps.

## Acceptance criteria
- [ ] `GET /admin/rides/live` returns online drivers and active rides; screen refreshes every 10 s.
- [ ] Counters: drivers online by class, rides by status, requests expired in the last hour.
- [ ] Requires `manage-rides`.
- [ ] Strings translated (EN/FR/RW/SW) and colours from `C.xxx` where UI is touched
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, with ownership checks in the controller
