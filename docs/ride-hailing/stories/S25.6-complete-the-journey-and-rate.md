## User story
**As a** passenger and driver,
**I want** to mark pickups, drop-offs and completion and rate each other,
**so that** journeys are recorded and trust grows.

## Acceptance criteria
- [ ] Driver marks each passenger picked up/dropped off; journey completes when the last stop is done.
- [ ] Ratings update the provider reputation shared with other services.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
