## User story
**As a** passenger or driver,
**I want** clear cancellation rules for seats and whole journeys,
**so that** everyone is treated fairly.

## Acceptance criteria
- [ ] Passenger cancels per the snapshot rules; driver cancelling the journey notifies every passenger.
- [ ] Seats are released per segment.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
