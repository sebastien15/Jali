## User story
**As a** rider,
**I want** to request a private car to another city now, with the driver's own price,
**so that** I can travel upcountry immediately.

## Acceptance criteria
- [ ] Intercity destinations show drivers who accept intercity trips, with their quote (including empty return if set).
- [ ] Links to existing scheduled private seats as a cheaper alternative.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
