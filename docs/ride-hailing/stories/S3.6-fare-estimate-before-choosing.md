## User story
**As a** rider,
**I want** to see a price range for my trip per vehicle class before picking a driver,
**so that** I know what to expect, like Uber's price per class.

## Acceptance criteria
- [ ] After entering a destination, I see classes (Moto, Car, Comfort, Van) with a price range (min–max of nearby quotes) and nearest ETA.
- [ ] Classes with no available drivers are shown greyed out.
- [ ] Tapping a class opens the nearby driver list filtered to that class.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
