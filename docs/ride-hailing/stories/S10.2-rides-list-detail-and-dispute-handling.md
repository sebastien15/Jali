## User story
**As a** admin,
**I want** to search rides and act on reported issues,
**so that** riders and drivers get fair resolution.

## Acceptance criteria
- [ ] Filters: status, date range, rider, driver, flagged.
- [ ] Detail shows timeline (`ride_events`), fare breakdown, ratings and reports.
- [ ] Admin can adjust final fare / commission with a mandatory note (logged).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
