## User story
**As a** marketing admin,
**I want** to create promo codes with amount/percent, expiry, usage limits and target segments,
**so that** we can run launch campaigns.

## Acceptance criteria
- [ ] Rider enters a code or it is auto-applied from a deep link; discount shown before requesting.
- [ ] Discount funded by Jali: driver earnings unaffected; ledger records it.
- [ ] Abuse limits: one per user/device, max uses, min fare.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
