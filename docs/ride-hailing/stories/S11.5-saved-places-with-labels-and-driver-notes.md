## User story
**As a** rider,
**I want** to save places like *Home – blue gate after the church* with a note for drivers,
**so that** repeat trips need zero explanation.

## Acceptance criteria
- [ ] Unlimited saved places with label, icon and optional note shown to the driver.
- [ ] Edit/delete; synced across devices via the account.
- [ ] Notes are shown to the driver only after accept.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
