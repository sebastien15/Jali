## User story
**As a** rider,
**I want** to save drivers I liked and request them first when they're online,
**so that** I can ride with people I trust.

## Acceptance criteria
- [ ] Heart a driver after a trip; favourites shown at top of nearby list when online.
- [ ] Can send a request directly to a favourite even slightly outside the radius.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
