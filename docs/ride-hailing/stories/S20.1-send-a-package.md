## User story
**As a** sender,
**I want** to send a package by moto or car with recipient details,
**so that** I can deliver things across the city quickly.

## Acceptance criteria
- [ ] Pickup + drop-off, recipient name/phone, size category, notes; driver quotes from their own rates.
- [ ] Photo at pickup and at delivery; recipient gets a tracking link.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
