## User story
**As a** owner and customer,
**I want** to record pickup and return with photos, fuel and odometer,
**so that** disputes about damage or fuel are rare and easy to settle.

## Acceptance criteria
- [ ] Check-out at pickup and check-in at return with photos, fuel level, odometer and notes from both sides.
- [ ] Late return is flagged; extra days follow the terms.
- [ ] Completed rental can be rated both ways.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
