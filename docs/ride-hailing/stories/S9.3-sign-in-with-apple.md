## User story
**As a** iPhone user,
**I want** to sign in with Apple,
**so that** I can log in privately — and Jali can be published on the App Store.

## Acceptance criteria
- [ ] *Sign in with Apple* button on iOS login screen.
- [ ] Backend verifies the Apple identity token (via Firebase) and returns a Sanctum token like Google login.
- [ ] Hidden-relay emails are supported.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added

## Notes
- Apple guideline 4.8 requires it when Google login is offered — listed as blocker in `store_requirements.md`.
