## User story
**As a** passenger,
**I want** to book one or more seats on a departure with passenger names,
**so that** I travel with a guaranteed seat.

## Acceptance criteria
- [ ] Quantity, passenger names, date and payment method; server-side price; no Jali fee.
- [ ] Clear confirmation state (requested vs confirmed) depending on the operator's flow.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
