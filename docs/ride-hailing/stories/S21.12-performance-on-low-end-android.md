## User story
**As a** rider with a cheap phone,
**I want** the app to start fast and stay smooth,
**so that** Jali works for everyone in Rwanda.

## Acceptance criteria
- [ ] Cold start < 3 s on a 2 GB RAM device; ride screens at 60 fps with map; app size budget documented.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
