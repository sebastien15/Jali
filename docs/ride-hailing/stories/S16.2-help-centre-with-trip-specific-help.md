## User story
**As a** user,
**I want** help articles relevant to my last trips,
**so that** I solve most problems myself.

## Acceptance criteria
- [ ] Help topics are managed by admins in all 4 languages.
- [ ] From a trip detail, I see contextual topics (charged wrong, driver behaviour, lost item).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
