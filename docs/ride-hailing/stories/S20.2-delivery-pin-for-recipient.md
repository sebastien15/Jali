## User story
**As a** sender,
**I want** the recipient to give a PIN to the driver,
**so that** the package reaches the right person.

## Acceptance criteria
- [ ] PIN sent to recipient by SMS; delivery can only be completed with the PIN or a photo + admin override.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
