## User story
**As a** driver,
**I want** to set my weekly working hours and block specific dates,
**so that** I only get hire requests when I'm free.

## Acceptance criteria
- [ ] Weekly schedule per weekday (start–end) and blocked dates.
- [ ] Accepted hires automatically block their time.
- [ ] Overlapping accepted hires are rejected server-side (`409`).
- [ ] Strings translated (EN/FR/RW/SW) and colours from `C.xxx` where UI is touched
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, with ownership checks in the controller
