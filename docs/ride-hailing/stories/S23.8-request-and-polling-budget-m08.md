## User story
**As a** user on a slow network,
**I want** the app to fetch only what the current screen needs,
**so that** it stays fast and cheap as services are added.

## Acceptance criteria
- [ ] Measured request counts for Home, Activity and Drive before/after; no all-service fan-out.
- [ ] Polling intervals and prefetching are reviewed per screen; list pagination everywhere.
- [ ] Results recorded in the migration log.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
