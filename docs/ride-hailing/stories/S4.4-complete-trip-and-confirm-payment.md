## User story
**As a** driver,
**I want** to end the trip and confirm how the rider paid,
**so that** both of us have a correct record.

## Acceptance criteria
- [ ] `POST /rides/{id}/complete` with `payment_method` (cash|momo) moves the ride to `completed` and sets `final_fare`.
- [ ] Rider sees a trip summary: route, distance, duration, fare breakdown (driver fare + Jali fee).
- [ ] Commission is written to the driver ledger.
- [ ] Only the assigned driver can complete, only from `in_progress`.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
