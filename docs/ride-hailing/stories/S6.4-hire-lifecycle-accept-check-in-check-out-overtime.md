## User story
**As a** driver and customer,
**I want** a clear lifecycle from request to completion,
**so that** time and money are recorded fairly.

## Acceptance criteria
- [ ] Driver can accept/decline within a configurable time; unanswered requests expire and the customer is told.
- [ ] Check-in and check-out record timestamps; overtime is computed automatically from the rate snapshot.
- [ ] Both sides get a summary and can rate each other.
- [ ] Cancellation policy (free until X hours before) is enforced.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
