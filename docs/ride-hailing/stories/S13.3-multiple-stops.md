## User story
**As a** rider,
**I want** to add up to 3 stops on my trip,
**so that** I can drop a friend or pick up something on the way.

## Acceptance criteria
- [ ] Stops added before or during the trip; quote recalculated and confirmed.
- [ ] Wait time at a stop beyond 3 min charged with the driver's per-minute rate.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
