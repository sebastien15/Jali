## User story
**As a** woman rider,
**I want** to choose to be matched only with women drivers,
**so that** I feel safer, especially at night.

## Acceptance criteria
- [ ] Option visible only to riders whose profile gender is female; only women drivers are shown or dispatched.
- [ ] Driver gender is verified during onboarding (S1.2).
- [ ] Legal review of the feature before launch.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
