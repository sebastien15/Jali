## User story
**As a** driver,
**I want** a map showing where ride requests are high right now,
**so that** I go where riders are and earn more.

## Acceptance criteria
- [ ] Hexagon heatmap of requests in the last 15 min and unserved requests.
- [ ] Refreshes every minute; no individual rider location is exposed.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
