## User story
**As a** driver,
**I want** a fair first-in-first-out queue when waiting at the airport,
**so that** waiting drivers are served in order.

## Acceptance criteria
- [ ] Queue position shown when inside the airport geofence (S10.4); leaving the zone removes me.
- [ ] Airport requests dispatched in queue order.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
