## User story
**As a** rider,
**I want** to share a live trip link with family or friends via WhatsApp/SMS,
**so that** someone knows where I am.

## Acceptance criteria
- [ ] *Share trip* creates a time-limited public link showing status, driver name/photo, car and plate, and approximate live position.
- [ ] Link expires when the ride ends.
- [ ] No rider personal data beyond first name is shown.
- [ ] Strings translated (EN/FR/RW/SW) and colours from `C.xxx` where UI is touched
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, with ownership checks in the controller
