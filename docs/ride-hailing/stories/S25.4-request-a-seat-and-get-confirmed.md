## User story
**As a** passenger,
**I want** to request seats and receive the driver's confirmation,
**so that** I know my seat is guaranteed.

## Acceptance criteria
- [ ] Request labelled *Requested* until the driver accepts; expiry if unanswered; seats held while pending.
- [ ] Confirmed passengers see the pickup agreement and driver contact; the driver sees a passenger list per stop.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
