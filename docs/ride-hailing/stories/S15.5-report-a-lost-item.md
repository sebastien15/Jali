## User story
**As a** rider,
**I want** to report an item I left in the car and contact the driver,
**so that** I get my things back.

## Acceptance criteria
- [ ] Available for 72 h after a trip; masked call or message to driver.
- [ ] Return delivery fee (driver-set) can be paid in-app; admin can follow up.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
