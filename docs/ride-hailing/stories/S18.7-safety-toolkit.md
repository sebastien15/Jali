## User story
**As a** rider or driver,
**I want** one shield button that opens every safety feature,
**so that** help is always one tap away.

## Acceptance criteria
- [ ] Contains SOS, share trip, trusted contacts, report incident, safety tips; visible on every trip screen.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
