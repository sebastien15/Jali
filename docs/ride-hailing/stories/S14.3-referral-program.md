## User story
**As a** rider or driver,
**I want** a personal invite code that rewards me and my friend,
**so that** Jali grows through word of mouth.

## Acceptance criteria
- [ ] Rider referral: credit for both after the friend's first completed ride.
- [ ] Driver referral: bonus after the referred driver completes N trips.
- [ ] Fraud checks: same device/phone/payment cannot self-refer.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
