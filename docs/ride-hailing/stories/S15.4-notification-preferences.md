## User story
**As a** user,
**I want** to choose which notifications I get (trip, promotions, news) and on which channel,
**so that** I only receive what I want.

## Acceptance criteria
- [ ] Trip-critical notifications cannot be disabled; marketing is opt-in and respected by campaigns.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
