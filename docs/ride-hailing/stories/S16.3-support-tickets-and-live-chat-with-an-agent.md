## User story
**As a** user,
**I want** to open a ticket or chat with a Jali agent about a trip,
**so that** a human helps me when needed.

## Acceptance criteria
- [ ] Ticket linked to ride/hire; status updates by push.
- [ ] Admin support inbox with assignment, SLA timers and canned replies.
- [ ] Safety tickets are prioritised.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
