## User story
**As a** driver,
**I want** reminders before my licence or insurance expires,
**so that** I'm never blocked unexpectedly.

## Acceptance criteria
- [ ] Reminders at 30, 7 and 1 day before expiry; automatic block on expiry until re-upload is approved.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
