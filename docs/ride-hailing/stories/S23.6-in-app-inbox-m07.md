## User story
**As a** user,
**I want** an inbox of my recent notifications with customer/provider/service filters,
**so that** I don't miss updates when push is off.

## Acceptance criteria
- [ ] Durable notification records with retention and deduplication; read/unread.
- [ ] Important status updates are always visible in-app even if push permission is denied.
- [ ] Respects notification preferences (S15.4).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
