## User story
**As a** developer,
**I want** rate limits on auth, OTP, nearby and request endpoints,
**so that** the API can't be abused or scraped.

## Acceptance criteria
- [ ] Per-IP and per-user limits with `429` responses; OTP limited to 5/hour per phone.
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
