## User story
**As a** rider,
**I want** to split the fare with friends in the car,
**so that** sharing a ride is easy.

## Acceptance criteria
- [ ] Invite Jali users by phone; each pays their share via in-app payment.
- [ ] If someone doesn't accept before trip end, the requester pays their share.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
