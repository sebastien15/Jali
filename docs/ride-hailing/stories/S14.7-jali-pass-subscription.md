## User story
**As a** frequent rider,
**I want** a monthly subscription with discounts and no service fee,
**so that** riding often is cheaper.

## Acceptance criteria
- [ ] Plans configurable by superadmin (price, discount %, perks).
- [ ] Auto-renewal from wallet; cancel anytime; benefits applied at quote time.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
