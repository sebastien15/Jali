## User story
**As a** ops admin,
**I want** to see, search and investigate driver hires like rides,
**so that** I can resolve hire problems quickly.

## Acceptance criteria
- [ ] `app/(admin)` hires list with status/date/customer/driver filters and a detail view with timeline, quote snapshot and ratings.
- [ ] Admin can correct check-in/check-out times with a required note; the change is logged in `activity_logs`.
- [ ] Requires `manage-rides` (or a new `manage-hires` permission appended to the seeder).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
