## User story
**As a** rider or driver,
**I want** to call the other party without seeing their real number,
**so that** my phone number stays private.

## Acceptance criteria
- [ ] Calls routed through a telephony provider's proxy number valid only during the trip + 2 h.
- [ ] Fallback to in-app chat if the provider is down.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
