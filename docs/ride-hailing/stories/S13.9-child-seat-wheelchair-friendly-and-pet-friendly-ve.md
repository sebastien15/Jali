## User story
**As a** rider,
**I want** to filter for vehicles with a child seat, wheelchair access or that accept pets,
**so that** families, people with disabilities and pet owners can ride.

## Acceptance criteria
- [ ] Vehicle capabilities are tags set by drivers and verified by admin photos.
- [ ] Filters on nearby list and estimate screen; optional surcharge set by the driver.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
