## User story
**As a** developer or tester,
**I want** a staging server with seed data and a script that moves fake drivers around Kigali,
**so that** every feature can be tested end-to-end without real drivers.

## Acceptance criteria
- [ ] `php artisan sim:drivers --count=50` moves drivers along real roads and auto-accepts requests (configurable).
- [ ] Staging app build points to staging API.
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
