## User story
**As a** driver,
**I want** levels based on rating, acceptance and trips with perks,
**so that** being a great driver pays off.

## Acceptance criteria
- [ ] Levels recalculated monthly; perks like lower commission or priority dispatch.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
