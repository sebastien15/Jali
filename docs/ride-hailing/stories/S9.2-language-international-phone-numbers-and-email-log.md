## User story
**As a** visitor,
**I want** the app in my language and to log in with my foreign phone number, email, Google or Apple,
**so that** I can start immediately after landing.

## Acceptance criteria
- [ ] App language defaults to the device language when supported (EN/FR/RW/SW), otherwise English; switchable in Profile.
- [ ] Phone login accepts any country code (+1, +33, +44, +254…), not only +250.
- [ ] Email and Google login work without a phone number; phone becomes optional but recommended for drivers to call.
- [ ] All new ride/hire strings exist in all four locale files.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
