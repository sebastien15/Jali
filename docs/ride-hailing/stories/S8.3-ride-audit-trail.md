## User story
**As a** admin,
**I want** every ride state change recorded with who, when and where,
**so that** disputes and incidents can be investigated.

## Acceptance criteria
- [ ] Each transition writes a `ride_events` row (actor, type, payload, timestamp).
- [ ] Admin ride detail shows the timeline.
- [ ] Events are append-only (no update/delete endpoints).
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
