## User story
**As a** driver,
**I want** ride request notifications that always arrive and ring loudly,
**so that** I never miss a request.

## Acceptance criteria
- [ ] High-priority FCM with a dedicated Android channel and custom sound for ride requests.
- [ ] Delivery and open rates tracked per notification type.
- [ ] SMS fallback for critical rider events (driver arrived) when push isn't opened within 60 s (configurable).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
