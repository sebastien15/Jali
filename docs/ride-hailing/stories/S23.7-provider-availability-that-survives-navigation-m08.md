## User story
**As a** driver,
**I want** my online status and location updates to keep working while I use other screens or customer mode,
**so that** I don't miss requests or go offline by accident.

## Acceptance criteria
- [ ] Presence heartbeat lives in a root coordinator, not in the Drive screen; one source for the header availability.
- [ ] Switching to customer mode does not take the driver offline; going offline is an explicit control.
- [ ] Background behaviour is explicit and documented (what runs when the app is backgrounded).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
