## User story
**As a** driver,
**I want** to publish a route with departure time, seats, stops and the fare between stops,
**so that** passengers along my route can join.

## Acceptance criteria
- [ ] Ordered stops (from existing stations/places) with times; fare per segment or per stop pair.
- [ ] Seats offered and pickup rules (custom pickup allowed or not).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
