## Goal
Drivers set their own per-km rates (unlike Yego/Uber fixed tariffs), within guardrails set by the superadmin; the server computes and locks every quote.

## Stories
- S2.1 — Driver sets own per-km rates with live preview (wave 3)
- S2.2 — Superadmin configures pricing guardrails & commission (wave 2)
- S2.3 — Server-side fare quote and price lock (wave 4)
