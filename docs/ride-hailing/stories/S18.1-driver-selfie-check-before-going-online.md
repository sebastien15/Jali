## User story
**As a** rider,
**I want** the driver to be the verified person,
**so that** nobody else drives with someone's account.

## Acceptance criteria
- [ ] Random selfie check when going online (at least daily); face match against verified selfie via a provider.
- [ ] Failure blocks going online and alerts admin; manual review path.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
