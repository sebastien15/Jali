## User story
**As a** rider,
**I want** Jali to check on me if the trip stops unusually long or goes off route,
**so that** help reaches me if something goes wrong.

## Acceptance criteria
- [ ] Detects stops > 5 min, route deviation > 1 km, unexpected early end.
- [ ] Both parties get an *Are you OK?* prompt with SOS / Report / I'm fine; no answer escalates to support.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
