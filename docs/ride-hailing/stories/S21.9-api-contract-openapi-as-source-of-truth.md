## User story
**As a** developer or AI agent,
**I want** an OpenAPI spec for every ride/hire endpoint with generated TypeScript types,
**so that** agents build mobile and backend in parallel, and the backend can later be rewritten (e.g. in Rust) without breaking the app.

## Acceptance criteria
- [ ] `docs/api/openapi.yaml` covers all new endpoints; CI fails if implementation and spec diverge (contract tests).
- [ ] Mobile uses generated types for requests/responses.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
