## User story
**As a** bus operator,
**I want** each departure on each date to have its own seat count,
**so that** tickets are never oversold.

## Acceptance criteria
- [ ] Seats are tracked per departure and date; bookings decrement atomically; sold-out departures are shown as such.
- [ ] Existing daily departure definitions keep working.
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
