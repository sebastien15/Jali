## User story
**As a** rider,
**I want** a Jali Wallet I can top up with MoMo or card and use for rides, receiving refunds and cashback,
**so that** paying is one tap and refunds are instant.

## Acceptance criteria
- [ ] Top-up via MoMo/card; balance and transaction history.
- [ ] Rides, hires and deliveries can be paid from wallet; partial wallet + other method supported.
- [ ] Double-entry ledger; reconciliation report for finance.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
