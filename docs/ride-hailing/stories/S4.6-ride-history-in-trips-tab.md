## User story
**As a** rider,
**I want** my rides listed with my bus/seat/rental bookings in the Trips tab,
**so that** all my Jali travel is in one place.

## Acceptance criteria
- [ ] Trips tab has a *Rides* filter; each item shows date, from → to, driver, fare and status.
- [ ] Tapping opens a detail with receipt and *Report an issue*.
- [ ] Paginated (`GET /rides`), cached with TanStack Query, skeleton while loading.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
