## User story
**As a** customer,
**I want** to send a rental request and be told quickly if the owner accepts,
**so that** I can plan my trip.

## Acceptance criteria
- [ ] Request is labelled *Requested* until the owner accepts; owner accepts/declines within a set time or it expires.
- [ ] Both sides get push + in-app updates; the dates are held while pending.
- [ ] Accepted rental shows owner contact and pickup instructions.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
