## User story
**As a** rider,
**I want** to change my destination mid-trip,
**so that** plans can change without ending the ride.

## Acceptance criteria
- [ ] New destination produces a new quote that I confirm; the driver is notified.
- [ ] Fare = distance already travelled at the old rate snapshot + new segment.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
