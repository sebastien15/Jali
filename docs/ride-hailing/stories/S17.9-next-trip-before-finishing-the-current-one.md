## User story
**As a** driver,
**I want** to receive a nearby next request near the end of my current trip,
**so that** I spend less time empty.

## Acceptance criteria
- [ ] Only requests whose pickup is close to my drop-off, offered in the last 3 min of the trip.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
