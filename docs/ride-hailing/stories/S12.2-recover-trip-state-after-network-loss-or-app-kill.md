## User story
**As a** rider or driver,
**I want** my active trip to reappear exactly where it was after reopening the app or regaining network,
**so that** a bad connection never breaks a trip.

## Acceptance criteria
- [ ] On launch, app calls `/rides/active` and routes to the active trip screen.
- [ ] Offline banner during network loss; queued actions (e.g. *arrived*) retried with idempotency keys.
- [ ] No duplicate state transitions from retries (test).
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
