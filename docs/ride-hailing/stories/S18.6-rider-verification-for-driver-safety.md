## User story
**As a** driver,
**I want** to know riders are verified, especially for cash rides at night,
**so that** I feel safe accepting requests.

## Acceptance criteria
- [ ] Verified phone required for all riders; ID verification required for cash rides at night (configurable).
- [ ] Verified badge shown on request card.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
