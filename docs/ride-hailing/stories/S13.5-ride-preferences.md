## User story
**As a** rider,
**I want** to set preferences like quiet ride, AC on, help with luggage,
**so that** the ride feels personal.

## Acceptance criteria
- [ ] Preferences saved on profile and shown to the driver on accept.
- [ ] Drivers can mark which preferences they support; filter in nearby list.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
