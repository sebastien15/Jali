## User story
**As a** rider or driver,
**I want** an SOS button during a trip,
**so that** I can get help fast in an emergency.

## Acceptance criteria
- [ ] SOS asks for confirmation, then calls 112 and sends my live location to my emergency contact.
- [ ] The ride is flagged in admin with a high-priority alert.
- [ ] I can set an emergency contact in Profile.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
