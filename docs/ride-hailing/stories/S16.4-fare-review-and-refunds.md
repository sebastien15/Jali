## User story
**As a** rider,
**I want** to request a fare review when I was overcharged,
**so that** I trust the prices.

## Acceptance criteria
- [ ] Automatic adjustment rules (e.g. route 30% longer than estimate without stop) issue refunds to wallet.
- [ ] Manual reviews by admin with reason; driver notified of adjustments.
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
