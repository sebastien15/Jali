## User story
**As a** rider,
**I want** to book a ride for a parent, friend or guest,
**so that** they travel safely even without the app.

## Acceptance criteria
- [ ] Pick a contact; the passenger gets an SMS with driver name, car, plate and live link.
- [ ] The PIN is sent to the passenger; I can track and pay.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
