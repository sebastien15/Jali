## Goal
Riders enter a destination, see nearby drivers with *their* price for this trip (DiDi-style), and request one driver or broadcast to all.

## Stories
- S3.1 — "Where to?" — start a ride from Home (wave 1)
- S3.2 — See nearby drivers with their own price (wave 6)
- S3.3 — Map of nearby drivers (wave 7)
- S3.4 — Request a specific driver (wave 7)
- S3.5 — Send request to all nearby drivers (wave 8)
- S3.6 — Fare estimate before choosing (wave 7)
