## User story
**As a** rider,
**I want** to choose a cheaper ride if I can wait, or pay more for the closest driver,
**so that** I control the trade-off between time and money.

## Acceptance criteria
- [ ] *Wait & save* broadcasts to drivers willing to give a discount for flexible pickup (≤ 15 min).
- [ ] *Priority* picks the nearest driver with a driver-set premium.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
