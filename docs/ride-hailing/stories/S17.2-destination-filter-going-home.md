## User story
**As a** driver,
**I want** to receive only trips heading toward my destination,
**so that** I can earn on my way home.

## Acceptance criteria
- [ ] Set a destination; only requests ending closer to it are dispatched.
- [ ] Usage limit per day configurable.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
