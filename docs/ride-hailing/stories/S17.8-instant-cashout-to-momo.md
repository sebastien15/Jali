## User story
**As a** driver,
**I want** to withdraw my in-app earnings to MoMo instantly,
**so that** I get my money when I need it.

## Acceptance criteria
- [ ] Available balance minus commission owed; small configurable fee; daily limit.
- [ ] Payout status tracked; failures returned to balance.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
