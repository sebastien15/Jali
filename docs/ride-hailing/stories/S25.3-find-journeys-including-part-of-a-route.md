## User story
**As a** passenger,
**I want** to search by my origin, destination and date and see journeys that pass through them,
**so that** I find a seat even when the driver goes further.

## Acceptance criteria
- [ ] Matches journeys whose stop order covers my origin before my destination; shows my segment fare and pickup point.
- [ ] Sorted by departure; empty state suggests nearby dates.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
