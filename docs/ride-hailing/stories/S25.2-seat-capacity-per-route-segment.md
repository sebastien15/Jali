## User story
**As a** driver,
**I want** seats counted per segment of my route,
**so that** I never carry more passengers than seats.

## Acceptance criteria
- [ ] A→C bookings occupy the seat on A→B and B→C; a passenger leaving at B frees the seat for B→C only.
- [ ] Overlapping requests are rejected atomically (concurrency test on MySQL).
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
