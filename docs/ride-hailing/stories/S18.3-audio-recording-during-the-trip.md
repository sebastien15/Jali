## User story
**As a** rider or driver,
**I want** to record trip audio, encrypted and only accessible if I report an incident,
**so that** there is evidence when something happens.

## Acceptance criteria
- [ ] Opt-in per trip or always; stored encrypted; nobody can listen unless attached to a safety report.
- [ ] Auto-deleted after 7 days if not reported; legal review required.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
