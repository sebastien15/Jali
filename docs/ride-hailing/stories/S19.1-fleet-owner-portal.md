## User story
**As a** fleet owner with several motos or cars,
**I want** to add vehicles, assign drivers and see earnings per vehicle,
**so that** I can run my transport business on Jali.

## Acceptance criteria
- [ ] Fleet owner role; vehicles owned by the fleet; drivers invited and linked.
- [ ] Earnings split between fleet owner and driver per configurable rule.
- [ ] Fleet dashboard: online vehicles, trips, earnings, documents expiring.
- [ ] Passes the UX quality checklist (`docs/ride-hailing/UX_QUALITY_CHECKLIST.md`)
- [ ] Routes inside `auth:sanctum` + `permission:<x>`, ownership checked in the controller, feature tests added
