### `npx expo export --platform web`: PASSES
Bundle built (2.64 MB JS, 7 kB CSS) and was exported to the scratchpad. The only warning was that the browserslist data is old.

### `npx expo-doctor`: 3 checks FAIL (see M-18)
- Missing peer dependency `expo-font`, which `@expo/vector-icons` needs.
- Duplicate native modules: `@expo/vector-icons` 14/15, `expo-constants` 18/17.1/17.0, `expo-linking` 8/7, `expo-application` 6.1/6.0.
- Versions that don't match SDK 54. Major: `@expo/vector-icons` 14 (needs 15), `expo-auth-session` 6 (7), `expo-crypto` 14 (15), `expo-localization` **55** (17), `expo-web-browser` 14 (15). Minor: `expo-notifications` 0.29 (0.32), `react-native-worklets` 0.8.1 (0.5.1), `netinfo`. Patch: `expo`, `expo-router`, `expo-constants`, `expo-image-picker`, `expo-linking`.

### i18n (script diffed `locales/*.json` against every `t("...")` call)
- All 4 locales hold the same 511 keys. None is missing in one locale but present in another.
- 4 keys are used in code but missing from **all** locales (see M-32).
- Many screens still hardcode English strings: legal pages, driver setup, BusResults, StationPicker, about 60 `Alert.alert` literals.

### Positive checks (no issue found)
- No mock data on the production path. `constants/data.ts` now holds only types and constants. `isDev` shortcuts (Google login bypass, Google Sign-In stub) are inactive because `.env` and `.env.production` both set `EXPO_PUBLIC_APP_ENV=prod`.
- The production API host `https://jali.stoka.rw/api` is live: `/api/me` returns 401 JSON. The old `/backend/public/api` path returns 404. `.claude/skills/deployment.md` and `context.md` §API still list the old and planned URLs and are out of date.
- No real secrets in the repo. The Firebase web config and the Google `webClientId` are public client identifiers.
