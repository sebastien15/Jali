# Jali Backend Audit (Laravel 11)

Reviewed on 2026-10-05 against `overnight-fixes` HEAD (38238c0), plus whatever was uncommitted in the working tree at the time. Scope: routes/, every controller (including Admin/), middleware, models, migrations, seeders, config (cors, sanctum, auth) and bootstrap/app.php.

"Verified" means I either traced the code path end to end or reproduced it with curl against `php artisan serve` on :8090 using the seeded SQLite DB.

**Notes**
- B-01 was reproduced on HEAD: `POST /api/auth/login` with `emmanuel@email.com` and the password `wrong` returned a token. While I was reviewing, an uncommitted edit to `AuthController::login` fixed it. Keep that fix and add a test for it.
- Test rows created during the audit: booking **#5** ("Fake", price 1, type bus, reference 999999). Admin claimed it, so it is now `taken`. There are also a few extra Sanctum tokens for emmanuel, joseph.driver, admin.kigali and superadmin. All of these can be deleted.
